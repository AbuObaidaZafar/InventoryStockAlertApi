# Inventory Stock Alert API

A robust Spring Boot REST API built with Java 26 to monitor product inventory levels and automatically trigger alerts when stock falls below defined thresholds.

## 🚀 Features
* **Full CRUD Management:** Easily add and view inventory items.
* **Smart Stock Adjustments:** Increment or decrement stock levels smoothly by product SKU.
* **Automated Low-Stock Tracking:** Dynamic filtering to pull a list of all items currently breaching their safety thresholds.

---

## 🛠️ Tech Stack & Requirements
* **Java:** Version 21
* **Framework:** Spring Boot 4.0.6 (Data JPA, Web)
* **Database:** H2 In-Memory Database (with H2 Console enabled), MySQl
* **Build Tool:** Maven
